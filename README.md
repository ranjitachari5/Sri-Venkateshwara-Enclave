# 🏡 Sri Venkateshwara Enclave

A responsive and modern real estate website developed for **Sri Venkateshwara Enclave**. The website showcases residential plots, project highlights, amenities, gallery, location, and contact details, providing visitors with all the essential information in an easy-to-navigate interface.

🌐 **Live Demo:** https://srivenkateshwaraenvclave.netlify.app/

---

## 📌 Features

- 📱 Fully responsive design
- 🏘️ Attractive landing page
- ℹ️ About the project section
- 🌳 Amenities showcase
- 🖼️ Project image gallery
- 📍 Location with Google Maps integration
- 📞 Contact information section
- ⚡ Smooth scrolling navigation
- 🚀 Fast loading and lightweight website

---
